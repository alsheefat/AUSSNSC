# AUSSNSC Android app

Kotlin + Jetpack Compose. Server address: `API_BASE_URL` in `gradle.properties`. Built by GitHub Actions (see the root README).

Files: `Api.kt` (network + login session), `GoogleAuth.kt` (Google/Firebase sign-in), `Specs.kt` (what each page loads), `Screens.kt` (screens), `MainActivity.kt` (navigation, home, profile, settings).
